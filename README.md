# FitAI Coach Project

This project implements a basic version of FitAI Coach, an AI-driven gym assistant.

## Project Structure

- `fitaicoach_core.py`: Contains the core machine learning logic, including data preprocessing, model training (Random Forest Classifier), and functions to get personalized workout plans and nutrition advice.
- `app.py`: A Flask web application that exposes API endpoints to access the FitAI Coach functionalities.
- `workout_model.pkl`: The pre-trained machine learning model (generated by `fitaicoach_core.py`).
- `requirements.txt`: Lists the Python dependencies required for this project.
- `README.md`: This file, providing an overview of the project.

## Setup and Installation

1.  **Clone the repository (if applicable) or download the files.**
2.  **Create a virtual environment (recommended):**
    ```bash
    python -m venv venv
    source venv/bin/activate  # On Windows: venv\Scripts\activate
    ```
3.  **Install dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

## Running the Application

1.  **Train the Model (if `workout_model.pkl` is not present or needs retraining):**
    Open a terminal and run the core script. This will train the model on the dummy data and save `workout_model.pkl`.
    ```bash
    python fitaicoach_core.py
    ```
    You should see output indicating the model accuracy and that the model has been saved.

2.  **Start the Flask API Server:**
    Once the model is saved, start the Flask application:
    ```bash
    python app.py
    ```
    The server will start, typically on `http://127.0.0.1:5001/`.

## API Endpoints

### 1. Get Personalized Workout Plan

-   **URL:** `/get_workout`
-   **Method:** `POST`
-   **Request Body (JSON):**
    ```json
    {
        "age": 30,
        "gender": "Male",
        "goal": "Muscle Gain",
        "activity_level": 4,
        "workout_performance": 8,
        "heart_rate": 135,
        "dietary_habits": "High Protein"
    }
    ```
    -   `gender`: "Male" or "Female"
    -   `goal`: "Weight Loss", "Muscle Gain", or "Maintenance"
    -   `dietary_habits`: "Balanced", "High Protein", or "Low Carb"
-   **Success Response (JSON):**
    ```json
    {
        "workout_plan": "Plan B" 
    }
    ```
-   **Error Response (JSON):**
    ```json
    {
        "error": "Missing fields: age"
    }
    ```

### 2. Get Nutrition Advice

-   **URL:** `/get_nutrition`
-   **Method:** `POST`
-   **Request Body (JSON):**
    ```json
    {
        "goal": "Weight Loss",
        "dietary_habits": "Low Carb"
    }
    ```
-   **Success Response (JSON):**
    ```json
    {
        "nutrition_advice": "Focus on lean proteins, plenty of vegetables, and healthy fats. Limit carbohydrate intake."
    }
    ```
-   **Error Response (JSON):**
    ```json
    {
        "error": "No input data provided"
    }
    ```

## How it Works

1.  **Data:** The `fitaicoach_core.py` script uses a small, hardcoded dataset (Pandas DataFrame) for demonstration purposes. In a real-world scenario, this data would come from a database populated with user information and real-time tracking.
2.  **Preprocessing:** Categorical features like `gender`, `goal`, and `dietary_habits` are converted into numerical representations using `astype('category').cat.codes`.
3.  **Model Training:** A `RandomForestClassifier` from `scikit-learn` is trained to predict a `workout_plan` based on user features.
4.  **Model Persistence:** The trained model is saved using `joblib.dump` and loaded using `joblib.load`.
5.  **Personalized Workout:** The `get_personalized_workout` function takes new user data, preprocesses it in the same way as the training data, and uses the loaded model to predict a suitable workout plan.
6.  **Nutrition Advice:** The `get_nutrition_plan` function provides basic, rule-based nutrition advice. A more advanced system would likely use another model or a more sophisticated knowledge base.
7.  **API:** The Flask `app.py` provides a simple REST API to interact with the core logic, allowing other applications (e.g., a mobile app) to get workout and nutrition recommendations.
